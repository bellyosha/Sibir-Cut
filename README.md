# Novatech Cut 0.2.6

Самостоятельная Windows-программа подготовки 2D-траекторий резки/рисования для Bambu Lab A1 с внешним механическим модулем UMTS и поворотным ножом Roland.

## Новое в 0.2.6

- рабочий файл больше не выполняет автоматический `G28`; homing выполняется вручную на экране A1 при снятом UMTS;
- в начале задания принудительно отправляются `M104 S0` и `M140 S0`, чтобы сопло и стол не нагревались;
- перед установкой и после окончания UMTS головка паркуется у переднего края стола, по умолчанию X128 Y10;
- старый стандартный профиль X20/Y240 автоматически мигрирует на новую парковку;
- фактическая траектория теперь проверяется с учётом Offset X/Y;
- выход за физические границы или безопасную область показывается в интерфейсе и блокирует экспорт;
- перетаскивание мышью также учитывает Offset X/Y и не позволяет вытолкнуть инструмент за безопасную область.

## Новое в 0.2.5

- объект на столе A1 можно выбрать и перетаскивать левой кнопкой мыши; движение ограничивается безопасной областью;
- добавлен режим рисования заполненных фигур: «Контур + заливка», «Только заливка», «Только контур»;
- заливка строится параллельными штрихами с настраиваемым шагом, углом, отступом от края и перекрёстным проходом;
- внутренние отверстия букв и фигур остаются пустыми при заливке;
- для резки используются только геометрические контуры с компенсацией поворотного ножа;
- слишком большие импортированные объекты автоматически уменьшаются до безопасной зоны;
- добавлен «Мастер подготовки и запуска»: файл → размещение → режим/материал → калибровка → воздушный тест → экспорт и запуск на A1;
- исправлена логика первой калибровки: больше нет циклического требования сначала выполнить воздушный тест, который сам был заблокирован до калибровки;
- мастер объясняет Offset X/Y, рабочую/безопасную Z и последовательность установки/снятия UMTS.

## Безопасность

По умолчанию профиль A1 имеет `calibrated=false`, поэтому физический экспорт заблокирован. Перед каждым запуском пользователь вручную выполняет Home на A1 при снятом UMTS. Сам рабочий файл не содержит `G28`, сразу отключает нагрев сопла/стола, поднимает Z и перемещает головку к переднему краю X128 Y10, где ставит `M400 U1` для установки UMTS. После установки модуля запрещены homing, ABL, ненулевой нагрев и экструзия. В конце инструмент поднимается, головка снова идёт к переднему краю и ставит вторую паузу для снятия UMTS.

**Первый запуск на реальном A1 должен быть только в режиме «Воздушный тест».** Совместимость сформированного `.gcode.3mf` с конкретной прошивкой A1 требуется подтвердить на реальном принтере — в среде разработки физического A1 нет.

## Запуск из исходников

`python -m novatech_cut`

Для конечного пользователя Python не нужен: Windows-сборка делается PyInstaller и Inno Setup скриптами из папки `build`.

## Проверка Windows-сборки

Workflow `.github/workflows/windows-build.yml` собирает `NovatechCut.exe`, запускает встроенный `--self-test`, проверяет portable ZIP, собирает Inno Setup, тихо устанавливает его на Windows runner и повторно запускает самотест уже из установленной программы. Артефакты публикуются только после успешного прохождения всех этих шагов.

Локальный диагностический режим без запуска GUI: `NovatechCut.exe --self-test` (код возврата 0 означает успешную программную проверку ядра и контейнера `.gcode.3mf`).
