# Sibir Cut 0.3.0

Самостоятельная Windows-программа подготовки 2D-траекторий резки/рисования для Bambu Lab A1 с внешним механическим модулем UMTS и поворотным ножом Roland.

## Новое в 0.3.0

- полностью переработано главное окно в стиле слайсера: слева объекты, в центре рабочий стол A1, справа только режим работы и основные действия;
- в главном окне режим выбирается одной парой кнопок «Резка / Рисование»;
- добавлены две основные кнопки «Нарезать» и «Нарезать и отправить»;
- подробные параметры материала, скоростей, проходов, штриховки, прижима ручки и Blade Offset перенесены в отдельное окно «Настройки задания»;
- подключение принтера вынесено в отдельное окно «Принтеры»: там находятся поиск Bambu в LAN, список сохранённых принтеров, access code и выбор активного A1;
- сохранённый активный принтер автоматически подключается при запуске Sibir Cut;
- добавлен новый пошаговый мастер калибровки: Home без UMTS → опорная метка → безопасная Z → рабочая/контактная Z → Offset X/Y → проверка;
- калибровка остаётся одноразовой для каждого инструмента и серийного номера A1, но любой шаг можно открыть и изменить позже;
- вопрос про центральные линии удалён из импорта растров: обычный импорт всегда строит геометрию/контуры;
- добавлена новая фирменная иконка Sibir Cut для EXE, установщика и ярлыка Windows;
- интерфейс получил светлую современную компоновку, скруглённые карточки и крупные основные кнопки.

## Новое в 0.2.17

- исправлен таймаут отправки файлов на Bambu Lab A1;
- передача для A1 больше не использует обычный `storbinary()`, который может зависать на ожидании финального FTP-ответа;
- файл передаётся вручную блоками по 64 КБ через `STOR`;
- для A1 сначала используется совместимый режим `PROT C` (TLS на управляющем соединении, data-канал без TLS), при необходимости есть fallback на `PROT P`;
- после передачи всех байтов Sibir Cut только коротко ждёт финальный `226`; таймаут этого ответа больше не считается ошибкой передачи;
- пользовательские `.gcode` теперь отправляются в корень хранилища принтера, а не в `/cache`, чтобы файл можно было выбрать с экрана A1;
- Sibir Cut только отправляет файл и никогда не запускает его автоматически — запуск выполняется вручную на принтере.

## Новое в 0.2.16

- добавлены отдельные постоянные калибровки для ножа и ручки; при выборе «Резка» или «Рисование» нужный профиль применяется автоматически;
- калибровка считается завершённой только когда отдельно сохранены Offset X/Y и Z выбранного инструмента;
- Offset теперь имеет однозначный физический смысл: `КОНЧИК = СОПЛО + OFFSET`; CAM автоматически переводит координаты кончика в координаты сопла;
- старые Offset автоматически мигрируют со сменой знака так, чтобы прежняя физическая траектория сопла не изменилась;
- в LAN-панели добавлена калибровка Offset по общей метке: сопло ставится в известную точку, затем кончик ножа/ручки совмещается с той же меткой, а X/Y вычисляются автоматически;
- калибровки ножа и ручки сохраняются отдельно для серийного номера выбранного A1 и восстанавливаются при следующем подключении;
- Z ножа сохраняется как рабочая глубина, Z ручки — как первое касание без нажима; прижим ручки остаётся отдельным параметром материала;
- добавлена локальная отправка `.gcode` на A1 по implicit FTPS/TLS, порт 990, логин `bblp`, пароль — сохранённый LAN access code;
- в 0.2.16 файл отправлялся в `cache/`; начиная с 0.2.17 ручные задания отправляются в корень хранилища A1;
- добавлены кнопки «Отправить последний экспорт», «Выбрать .gcode и отправить…» и «Экспорт + отправить по LAN»;
- LAN-передача не запускает задание автоматически: запуск всегда выполняется отдельно с экрана A1;
- мастер запуска обновлён под новый LAN-сценарий; microSD оставлена как резервный вариант.

## Безопасность

По умолчанию профиль A1 имеет `calibrated=false`, поэтому физический экспорт заблокирован. Перед каждым запуском Home выполняется при снятом UMTS — с экрана A1 либо кнопкой Home в LAN-панели Sibir Cut. Сам рабочий файл не содержит `G28`, сразу отключает нагрев сопла/стола, поднимает Z и перемещает головку к переднему краю X230 Y10, где выполняет `M400 S10` для установки UMTS. После установки модуля запрещены homing, ABL, ненулевой нагрев и экструзия. В конце инструмент поднимается, головка снова идёт к переднему краю и выполняет второе `M400 S10` для снятия UMTS.


## Запуск из исходников

`python -m novatech_cut`

Для конечного пользователя Python не нужен: Windows-сборка делается PyInstaller и Inno Setup скриптами из папки `build`.

## Проверка Windows-сборки

Workflow `.github/workflows/windows-build.yml` собирает `SibirCut.exe`, запускает встроенный `--self-test`, проверяет portable ZIP, собирает Inno Setup, тихо устанавливает его на Windows runner и повторно запускает самотест уже из установленной программы. Артефакты публикуются только после успешного прохождения всех этих шагов.

Локальный диагностический режим без запуска GUI: `SibirCut.exe --self-test` (код возврата 0 означает успешную программную проверку ядра и контейнера `.gcode.3mf`).
