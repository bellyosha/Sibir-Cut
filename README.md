**Sibir Cut** — Windows-приложение для использования **Bambu Lab A1** как 2D-станка для рисования и резки с внешним держателем инструмента: ручкой, маркером или поворотным ножом.

## Что умеет Sibir Cut

### Работа с рисунками

Поддерживается импорт:

- SVG;
- DXF;
- PNG;
- JPG / JPEG;
- BMP;
- WebP.

Растровые изображения преобразуются в геометрию/контуры.

На виртуальном столе Bambu Lab A1 можно:

- перетаскивать объект мышью;
- вращать его за круглый маркер;
- удерживать **Shift** при вращении для шага 15°;
- менять размер за квадратный маркер;
- задавать X/Y, масштаб и угол вручную;
- дублировать объекты;
- выравнивать объекты;
- зеркалить отдельные объекты;
- отменять изменения через Ctrl+Z.

Все трансформации отображаются прямо на столе в реальном времени.

### Резка и рисование

В главном окне доступны два режима:

- **РЕЗКА** — работа поворотным ножом;
- **РИСОВАНИЕ** — работа ручкой или маркером.

Для каждого режима Sibir Cut автоматически применяет собственную сохранённую калибровку инструмента.

### Зеркальный режим

Переключатель **«Зеркально / наизнанку»** отражает всю готовую траекторию по горизонтали.

Это удобно для:

- термопереноса;
- наклеек;
- шаблонов;
- работ, которые после переноса должны читаться в нормальной ориентации.

Зеркальный результат сразу виден на виртуальном столе до создания G-code.

### Настройки резки

Можно задавать:

- количество проходов;
- рабочую скорость;
- скорость холостых перемещений;
- Blade Offset;
- Overcut;
- рабочую Z;
- безопасную Z.

Для поворотного ножа используется компенсация смещения режущей кромки и обработка поворотов.

### Настройки рисования

Доступны:

- только контур;
- только заливка;
- контур + заливка;
- шаг штриховки;
- угол штриховки;
- перекрёстная штриховка;
- отступ штриховки от края;
- прижим ручки;
- высота подъёма ручки.

Внутренние отверстия букв и фигур сохраняются при штриховке.

## Подключение Bambu Lab A1 по LAN

Sibir Cut умеет находить A1 в локальной сети.

В окне **«Принтеры»** находятся:

- автоматический поиск Bambu Lab в сети;
- список найденных принтеров;
- список сохранённых принтеров;
- IP;
- серийный номер;
- LAN access code;
- выбор активного принтера;
- ручное подключение;
- расширенное LAN-управление.

После первого успешного подключения выбранный принтер сохраняется.

При следующих запусках Sibir Cut автоматически пытается подключиться к нему.

LAN access code сохраняется локально на компьютере только если пользователь включил соответствующую опцию.

## Отправка файлов на принтер

После подготовки задания есть две основные кнопки:

### НАРЕЗАТЬ

Создаёт готовый G-code на компьютере.

### НАРЕЗАТЬ И ОТПРАВИТЬ

Sibir Cut:

1. создаёт G-code;
2. подключается к A1 по локальной сети;
3. отправляет файл в хранилище принтера;
4. завершает передачу.

**Sibir Cut не запускает задание автоматически.**

После отправки файл запускается вручную с экрана Bambu Lab A1.

## Калибровка инструмента

Для ножа и ручки хранятся отдельные профили.

Калибровка привязывается к выбранному принтеру и его серийному номеру.

Обычно её достаточно выполнить один раз, после чего Sibir Cut автоматически применяет сохранённые значения. Любой этап можно открыть повторно и изменить.

### 1. Home

Перед Home снимите UMTS / держатель инструмента, если он мешает штатным движениям головы.

После Home дождитесь полной остановки принтера.

### 2. Опорная точка сопла

Программа перемещает сопло в известную точку.

Сделайте физическую метку точно под соплом — например, на бумаге или малярной ленте.

Эта метка используется для вычисления положения ножа или ручки относительно сопла.

### 3. Безопасная Z

Подберите высоту, на которой инструмент гарантированно не касается материала.

Она используется для холостых перемещений.

### 4. Рабочая / контактная Z

Для ножа задаётся рабочая глубина.

Для ручки сохраняется первое касание материала без нажима.

Дополнительный прижим ручки настраивается отдельно в параметрах задания.

### 5. Offset X/Y

После установки инструмента перемещайте голову кнопками X/Y, пока кончик ножа или ручки точно не попадёт в ранее сделанную метку.

Sibir Cut сам вычислит смещение.

Используется правило:

`КОНЧИК ИНСТРУМЕНТА = СОПЛО + OFFSET`

Знак Offset вручную вычислять не нужно.

## Рабочий процесс

Обычная последовательность выглядит так:

1. Запустить Sibir Cut.
2. Дождаться подключения сохранённого A1.
3. Импортировать рисунок.
4. Расположить его на виртуальном столе.
5. При необходимости повернуть или изменить размер мышью.
6. Выбрать **Резка** или **Рисование**.
7. При необходимости включить **«Зеркально / наизнанку»**.
8. Открыть **«Настройки задания»** и проверить параметры.
9. Нажать **«Нарезать»** или **«Нарезать и отправить»**.
10. Если файл отправлен по LAN — запустить его вручную с экрана A1.

## Работа с UMTS

Стандартный G-code Sibir Cut не выполняет автоматический Home во время задания.

Перед началом работы Home выполняется при снятом UMTS.

Рабочий файл:

- отключает нагрев сопла;
- отключает нагрев стола;
- не выполняет экструзию;
- поднимает инструмент на безопасную Z;
- перемещает голову к доступному переднему краю;
- делает короткую паузу для установки UMTS;
- выполняет рисование или резку;
- после задания возвращает голову к переднему краю;
- делает паузу для снятия UMTS.

По умолчанию используется парковка около **X230 Y10**.

## Предпросмотр и контроль

На виртуальном столе отображаются:

- рабочая область A1;
- безопасные отступы;
- рабочая траектория;
- холостые перемещения;
- направление движения;
- положение и размер объектов.

Есть анимация готовой траектории.

Перед экспортом Sibir Cut проверяет выход инструмента и сопла за допустимые границы.

При опасной траектории экспорт блокируется.

- их положение;

- поворот;
- зеркальность;

- режим работы;
- настройки траектории.

## Системные требования

- Windows 10 / Windows 11;
- 64-битная система;
- Bambu Lab A1 для LAN-функций;
- компьютер и принтер в одной локальной сети.

Для установленной Windows-версии Python не требуется.

## Безопасность

Sibir Cut управляет реальным движением печатающей головы и внешнего инструмента.

Перед первым запуском нового инструмента, материала или профиля:

- используйте тестовый материал;
- проверьте безопасную Z;
- проверьте Offset X/Y;
- убедитесь, что UMTS не мешает Home;
- не оставляйте принтер без присмотра.
