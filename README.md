# Novatech Cut 0.1.1

Самостоятельная Windows-программа подготовки 2D-траекторий резки/рисования для Bambu Lab A1 с внешним механическим модулем UMTS и поворотным ножом Roland.

## Исправлено в 0.1.1

- устранено зависание после преобразования сложных растров;
- импорт/векторизация и первая подготовка траектории выполняются без блокировки окна;
- большие изображения автоматически обрабатываются в ограниченном рабочем разрешении с сохранением физического масштаба;
- добавлены ограничения сложности и быстрые алгоритмы для тысяч контуров;
- предпросмотр и холст больше не создают тысячи стрелок/подписей;
- добавлен регрессионный Windows-тест большой растровой картинки.

## Что уже реализовано

- импорт SVG, DXF, PNG/JPG/JPEG/BMP;
- векторизация растров по внешнему контуру или центральным линиям, порог, инверсия, сглаживание и предпросмотр;
- рабочее поле A1 256×256 мм, сетка, безопасные отступы, масштабирование;
- перемещение/масштаб/поворот/зеркало/дублирование и выравнивание объектов, undo/redo;
- удаление дублей, объединение близких концов, упрощение и оптимизация порядка;
- внутренние замкнутые контуры идут раньше крупных внешних;
- компенсация поворотного ножа (blade offset + поворот вокруг углов + overcut);
- режимы резки и рисования, несколько проходов, рабочая/безопасная Z;
- обязательная калибровка профиля перед экспортом;
- воздушный тест;
- генерация G-code без экструзии и нагрева;
- повторный разбор G-code с блокировкой опасных/неизвестных команд;
- упаковка `.gcode.3mf`, обычный `.gcode`, отчёт JSON, проект `.ncut`;
- редактируемый профиль оборудования (отступы, X/Y offset, Z, парковка, ограничения, старт/конец G-code) с импортом/экспортом JSON;
- мастер калибровки, который ничего не отправляет на принтер автоматически;
- визуализация направления, красной рабочей траектории, синего холостого хода и анимация;
- тестовый набор SVG/DXF/PNG и автоматические тесты.

## Безопасность

По умолчанию профиль A1 имеет `calibrated=false`, поэтому физический экспорт заблокирован. Стартовая последовательность делает `G28` до установки UMTS, паркует головку и использует подтверждённую паузу Bambu `M400 U1`. После установки модуля генератор запрещает homing, ABL, нагрев и экструзию. В конце инструмент поднимается, головка паркуется и снова ставится пауза для снятия UMTS.

**Первый запуск на реальном A1 должен быть только в режиме «Воздушный тест».** Совместимость сформированного `.gcode.3mf` с конкретной прошивкой A1 требуется подтвердить на реальном принтере — в среде разработки физического A1 нет.

## Запуск из исходников

`python -m novatech_cut`

Для конечного пользователя Python не нужен: Windows-сборка делается PyInstaller и Inno Setup скриптами из папки `build`.

## Проверка Windows-сборки

Workflow `.github/workflows/windows-build.yml` собирает `NovatechCut.exe`, запускает встроенный `--self-test`, проверяет portable ZIP, собирает Inno Setup, тихо устанавливает его на Windows runner и повторно запускает самотест уже из установленной программы. Артефакты публикуются только после успешного прохождения всех этих шагов.

Локальный диагностический режим без запуска GUI: `NovatechCut.exe --self-test` (код возврата 0 означает успешную программную проверку ядра и контейнера `.gcode.3mf`).
